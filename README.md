# Superstore Sales Dashboard (Excel)

## Project Overview
This project is an interactive Excel dashboard built using the Superstore dataset. The dashboard helps analyze sales performance, profit, orders, and customer segments through charts, KPI cards, and slicers.

## Dashboard Preview

![Dashboard](dashboard.png)

## Features
- Interactive Slicers (Region, Category, Segment, Year)
- KPI Cards
- Sales Trend Analysis
- Sales by Region
- Sales by Category
- Orders by Segment
- Top Products Analysis

## Skills Used
- Data Cleaning
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Slicers
- Dashboard Design
- Data Visualization

## Key Insights
- West region generated the highest sales.
- Technology category contributed the highest revenue.
- Consumer segment placed the highest number of orders.
- Sales performance varied across regions and categories.
